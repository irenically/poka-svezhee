# Пока свежее

Мобильный веб-прототип для учёта продуктов в холодильнике и морозилке.

## Запуск

```sh
npm install
npm run dev
```

## Что работает

- Добавление продукта по названию или штрихкоду.
- Поиск штрихкода в Open Food Facts; неизвестный товар можно назвать вручную.
- Сканирование камерой через ZXing, ручной ввод кода как запасной путь.
- Количество, место хранения, дата на упаковке или ориентировочная дата проверки.
- Сортировка по срочности, редактирование, отметки «съели» и «выбросили».
- Запасы сохраняются в localStorage текущего браузера.

Данные пока не синхронизируются между устройствами. Встроенные сроки хранения свежих продуктов и уведомления добавим после проверки справочника и выбора общей базы. Для работы камеры нужен HTTPS или localhost.
